# 🛒 TechSway – Digital Mart

A full-stack **Digital Mart / E-Commerce Web Application** built using **Node.js, Express, SQL**, and a **static HTML, CSS, and JavaScript frontend**.
TechSway allows users to browse electronic products, manage carts and wishlists, place orders, and subscribe to a **“Notify Me” system** that sends **email alerts via SendGrid** when products are back in stock.

---

## 🚀 Features

* 🛍️ Product listings (Phones, Laptops, Smartwatches, Earbuds)
* ❤️ Wishlist management
* 🛒 Cart & order management
* 📩 “Notify Me” email subscription for out-of-stock products
* ✉️ Automated email alerts using SendGrid
* 📄 User account & order history pages
* 🌐 RESTful APIs with Express
* 🗄️ SQL database integration
* 📱 Responsive UI (Desktop & Mobile)
* 🚀 Deployed on Render

---

## 🛠️ Tech Stack

### Frontend

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone <repository-url>
cd swayams-digital-mart
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Server

```bash
node server.js
```

Server runs on:

```
http://localhost:4000
```
